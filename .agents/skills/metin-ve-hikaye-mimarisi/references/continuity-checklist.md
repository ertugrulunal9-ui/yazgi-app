# Continuity Checklist

Run this checklist before returning final dialogue or events.

## Story Logic

- Verify chronology: no effect appears before its cause.
- Verify world rules: no output breaks explicit lore constraints.
- Verify knowledge scope: characters only reference known facts.
- Verify POV and tense consistency inside the same scene.

## Character Consistency

- Verify each speaker keeps distinct voice markers.
- Verify mood score influences tone and risk posture.
- Verify skill tier changes strategy, not only wording.
- Verify relationship state changes how direct or indirect lines are.

## Gameplay Coherence

- Verify event triggers are reachable by normal progression.
- Verify at least one player choice is viable in common states.
- Verify consequences are meaningful but not arbitrarily punishing.
- Verify cooldown prevents repeated farming loops.

## Output Hygiene

- Return schema-valid JSON when structured output is requested.
- Keep lines concise; remove repeated phrases and filler exposition.
- Add a short assumptions block when input constraints are missing.
